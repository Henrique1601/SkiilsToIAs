# ✨ Magic UI Design MCP Server (`magicuidesign-mcp`)

Servidor oficial do **Magic UI MCP** (`@magicuidesign/mcp`) para catálogo e geração de componentes modernos de interface de usuário (React, Next.js, Tailwind CSS e Framer Motion).

---

## ⚡ Configuração & Transporte

- **Tipo / Transporte:** Stdio (Execução local via Node/npx)
- **Pacote:** `@magicuidesign/mcp@latest`

### Exemplo de Configuração:

```json
{
  "mcpServers": {
    "magicuidesign-mcp": {
      "command": "npx",
      "args": ["-y", "@magicuidesign/mcp@latest"]
    }
  }
}
```

---

## 🛠️ Principais Recursos e Capacidades
- **Catálogo de Componentes:** Consulta e importação de componentes ricos (bento grids, partículas, texto animado, bordas radiantes, dock de navegação).
- **Código Fonte Limpo:** Código pronto para colar em projetos React/Next.js integrados com Tailwind CSS.
- **Sinergia:** Potencializa o `design-engineer-agent` e acelera a criação de landing pages modernas no Padrão Ouro.
